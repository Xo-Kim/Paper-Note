# 📄 Paper Notes

논문을 읽으면서 **밑줄 · 개념 필기 · 모르는 단어 정리 · 노트 작성**을 한 화면에서 할 수 있는 웹 앱입니다.
설치나 서버 없이 `PaperNotes.html` 파일 하나를 브라우저로 열면 바로 쓸 수 있어요.

- 왼쪽: 논문 본문 (PDF 원문 그대로 보기 / 추출한 텍스트로 보기)
- 오른쪽: 노트 · 밑줄 · 개념 · 단어 탭

---

## 시작하기

1. `PaperNotes.html`을 Chrome 또는 Edge로 엽니다.
2. PDF 파일을 화면에 끌어놓거나, **＋ 새 논문** 버튼으로 PDF를 고르거나 본문 텍스트를 붙여넣습니다.
3. 본문을 드래그하면 밑줄 메뉴가 뜹니다.

> PDF.js와 MathJax를 CDN에서 불러오므로 처음 PDF를 열거나 수식을 쓸 때는 인터넷 연결이 필요합니다.

---

## 주요 기능

### 📖 논문 읽기
- **PDF 원문 보기**: 원본 PDF를 그대로 띄우고, 그 위에서 글자를 선택해 밑줄을 그을 수 있습니다.
  확대/축소, 화면 너비 맞춤을 지원하고, 화면 근처의 쪽만 그려서 긴 논문도 가볍게 열립니다.
- **텍스트 보기**: PDF에서 추출한 문단을 읽기 편한 글꼴로 보여줍니다.
  2단 편집 논문의 단 순서, 하이픈 줄바꿈, 쪽 번호 줄을 자동으로 정리합니다.
- **텍스트 붙여넣기**: PDF가 없어도 본문을 붙여넣어 논문을 만들 수 있습니다 (빈 줄로 문단 구분).
- 한글 등 CJK 글꼴 PDF도 텍스트를 추출합니다.
- 논문마다 마지막으로 보던 위치와 보기 방식을 기억합니다.

### ✏️ 밑줄 — 색으로 분류
| 색 | 의미 | 모이는 탭 | 메모 |
|---|---|---|---|
| 🔴 빨강 | 모르는 **개념** | 개념 | 밑줄을 긋자마자 필기 입력창이 열림 |
| 🔵 파랑 | 모르는 **단어** | 단어 | 뜻을 바로 입력 |
| 🟢 초록 | 중요한 문장 | 밑줄 | — |

- 밑줄을 클릭하면 색 변경 · 필기 수정 · 삭제 · 노트로 인용을 할 수 있습니다.
- 필기가 있는 밑줄에 마우스를 올리면 내용이 툴팁으로 보입니다.
- 각 탭의 항목을 클릭하면 본문의 해당 위치로 이동하고 잠깐 강조 표시됩니다.

### 📝 노트 (Notion 스타일 블록 편집기)
- **Markdown 지원**: `# 제목`, `- 목록`, `1. 번호`, `- [ ] 체크리스트`, `> 인용`, ` ``` 코드 ``` `, `---`, `**굵게**`, `*기울임*`, `~~취소선~~`, `==강조==`, 링크
- 블록 맨 앞에서 `# `, `- `, `1. `, `> `, `[] `를 입력하면 바로 해당 블록으로 바뀝니다.
- **수식**: `$인라인 수식$`, `$$블록 수식$$` (MathJax로 렌더링)
- **이미지**: 붙여넣기(Ctrl+V) 또는 노트 패널에 끌어놓기
- **본문 인용**: 본문을 선택하고 `❝ 노트로`를 누르면 인용 블록과 함께 **원문 위치 링크(↗)** 가 붙고, 클릭하면 그 위치로 이동합니다.
- **블록 다루기**: `⋮⋮` 손잡이로 끌어서 순서 바꾸기, 마우스로 세로로 끌어 여러 블록 선택, 선택한 블록 삭제·복사·묶어서 이동

### 💾 저장 · 내보내기
- **자동 저장**: 편집하면 바로 저장됩니다 (`Ctrl+S`로 즉시 저장도 가능).
- **실행 취소 / 다시 실행**: `Ctrl+Z` / `Ctrl+Shift+Z` (또는 `Ctrl+Y`)로 노트와 밑줄 변경을 되돌립니다. 논문을 열 때마다 기록이 새로 시작됩니다.
- **브라우저 저장 (기본)**: IndexedDB에 저장되어 같은 브라우저에서 다시 열면 그대로 이어서 볼 수 있습니다.
- **폴더 저장 (Chrome/Edge)**: `📁 폴더 연결`을 누르고 위치를 고르면 아래처럼 실제 파일로 저장됩니다. 브라우저에 있던 논문도 함께 옮겨집니다.
  ```
  <선택한 위치>/papers/
  └── <논문 제목>/
      ├── paper.json        # 앱 데이터 (본문, 밑줄, 노트)
      ├── <논문 제목>.md     # 노트 + 밑줄 정리본 (Notion 가져오기용)
      ├── original.pdf      # 원본 PDF
      └── images/           # 노트에 넣은 이미지
  ```
  보안상 브라우저를 다시 열 때마다 `📁 폴더 다시 연결`로 한 번 허용해야 합니다.
  폴더 모드에서 논문을 삭제하면 그 논문 폴더(PDF·이미지 포함)도 함께 완전히 지워집니다.
- **Markdown 내보내기**: 노트 + 밑줄 + 개념 + 단어를 `.md` 파일로 저장하거나 클립보드에 복사 (Notion에 바로 붙여넣기 좋게 변환)
- **JSON 백업/복원**: 논문 하나를 노트 속 이미지까지 포함해 `.json` 하나로 백업하고 다시 불러올 수 있습니다.
- 같은 PDF(파일명+크기)를 다시 끌어놓으면 새로 만들지 않고 기존 논문을 엽니다.

### 🌙 다크 모드
- 상단 바의 🌙 / ☀️ 버튼으로 전환합니다. 고른 테마는 저장됩니다.
- 직접 고른 적이 없으면 운영체제(시스템)의 다크 모드 설정을 따라갑니다.
- **PDF 어둡게** (PDF 보기 툴바의 ◐, 기본 켬): PDF 원문도 검은 바탕에 밝은 글자로 바꿔 보여줍니다.
  논문 속 **사진은 위치를 찾아내 원래 색 그대로** 둡니다.
  흰 바탕의 그래프·도표(이미지든 도형이든)는 글자처럼 검은 바탕으로 바뀌고, 막대·선의 색감은 비슷하게 유지됩니다.
  ◐를 끄면 PDF가 원래의 흰 종이로 (살짝 어둡게) 표시됩니다.

## 단축키

### 본문에서 (텍스트를 드래그해 선택한 상태)
| 키 | 동작 |
|---|---|
| `1` | 빨강 밑줄 (개념) |
| `2` | 파랑 밑줄 (단어) |
| `3` | 초록 밑줄 |
| `U` | 마지막에 쓴 색으로 밑줄 |
| `N` | 노트로 인용 |
| `Esc` | 선택 메뉴 닫기 |

> `⋯` 메뉴 → **⌨ 단축키 설정**에서 원하는 키(조합)로 바꿀 수 있습니다. 한글 입력 상태에서도 같은 키로 동작합니다.

### 어디서든
| 키 | 동작 |
|---|---|
| `Ctrl+Z` | 실행 취소 (노트·밑줄) |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 다시 실행 |
| `Ctrl+S` | 바로 저장 |
| `Ctrl+F` | 찾기 — 본문(PDF 전체 쪽) · 노트 · 필기(개념·단어 탭의 밑줄 단어와 적어 둔 내용). **전체 / 본문 / 노트 / 필기** 버튼으로 범위를 고르고, 버튼마다 찾은 개수가 보입니다. `Enter` 다음, `Shift+Enter` 이전, `Esc` 닫기 |

### 노트에서
| 키 | 동작 |
|---|---|
| `Enter` / `Shift+Enter` | 새 블록 / 블록 안 줄바꿈 |
| `Tab` / `Shift+Tab` | 들여쓰기 / 내어쓰기 |
| `Backspace` (블록 맨 앞) | 블록 종류 해제 → 내어쓰기 → 앞 블록과 합치기 |
| `↑` / `↓` | 위/아래 블록으로 이동 |
| `Ctrl+Shift+↑/↓` | 블록 위/아래로 옮기기 |
| `Ctrl+Shift+E` | 선택한 글자를 `$수식$`으로 감싸기/풀기 |
| `Ctrl+B` / `Ctrl+I` | 굵게 / 기울임 |
| `Esc` | 편집 끝내고 블록 선택 |

### 블록을 선택한 상태
| 키 | 동작 |
|---|---|
| `Delete` / `Backspace` | 선택한 블록 삭제 |
| `Ctrl+C` | 선택한 블록 복사 |
| `Enter` | 편집 시작 |
| `↑` / `↓`, `Shift+↑/↓` | 선택 이동 / 범위 넓히기 |
| `Ctrl+Shift+↑/↓` | 선택한 블록 묶어서 옮기기 |
| `Shift+클릭` | 범위 선택 |

## 기술 스택
- 순수 HTML · CSS · JavaScript (빌드 도구, 프레임워크, 서버 없음)
- [PDF.js](https://mozilla.github.io/pdf.js/) 3.11 — PDF 렌더링 · 텍스트 추출
- [MathJax](https://www.mathjax.org/) 3 — 수식 렌더링
- IndexedDB / File System Access API — 저장

## 브라우저 지원
| 브라우저 | 지원 |
|---|---|
| Chrome, Edge | 모든 기능 |
| Firefox, Safari | 폴더 저장을 뺀 모든 기능 (브라우저 저장만 사용) |

## 코드 구조
`PaperNotes.html` 한 파일 안에 CSS와 JavaScript가 모두 들어 있습니다. 스크립트는 번호 붙은 구역으로 나뉘어 있습니다.

| 구역 | 내용 |
|---|---|
| 1–3 | 유틸 · 상수, 저장소(IndexedDB / 폴더), 자동 저장 |
| 4–5 | 본문 보기 (텍스트 / PDF 원문), PDF 어둡게 (사진 영역 찾기) |
| 6–9 | 밑줄 툴바 · 팝업, 단축키, 주석 목록 탭, 원문 위치 이동 |
| 10–11 | Markdown · 수식 렌더링, 노트 블록 편집기, 찾기(Ctrl+F) |
| 12–14 | 전역 이벤트, 논문 목록 · 열기 · 새 논문 |
| 15 | PDF → 문단 텍스트 추출 |
| 16–19 | 내보내기 · 가져오기, 폴더 연결, 테마(다크 모드), 시작 |
